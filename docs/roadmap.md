# cs-agent 路线图

> 节奏：30 天冲刺（2026-10-04 启动开发）。原则：**每个版本必须可运行、有验收标准**。

## v0.1 · 骨架与意图路由（10.04–10.05）

- [ ] 仓库初始化：目录结构、配置管理（.env + 配置类）
- [ ] 架构图定稿（意图路由 / RAG / 工具层 / 记忆 / 兜底）
- [ ] 意图识别模块（结构化输出，Day1 手写代码迁移复用）
- [ ] 简单命令行对话入口

验收：命令行输入一句话，正确输出意图 JSON。

## v0.5 · Agent 内核（10.05–10.07）

- [ ] 手写 Function Calling 循环（工具注册表：订单查询 / 库存查询 / 工单创建）
- [ ] RAG 链路接入（复用网盘项目经验：切片 / pgvector / TopK）
- [ ] 对话记忆（多轮上下文）
- [ ] 转人工雏形（低置信度判定）

验收：多轮对话中能正确调用工具并引用知识库回答。

## v1 · 可演示版本（10.09–10.11）

- [ ] LangGraph 图编排重构（对照手写版本，理解框架价值）
- [ ] Web 界面（对话 + 转人工提示 + 工单确认）
- [ ] Docker 部署上线
- [ ] README 完善（架构图 / 演示动线）

验收：可访问的线上 Demo + 演示视频。

## v1.5 · 评测体系（10.16–10.18）

- [ ] 评测脚本：意图准确率 / 检索命中率 / 首响延迟 / 转人工率
- [ ] 基准数据集（客服 QA 对 ≥ 100 条）
- [ ] 失败 case 分析与迭代

## v2 · 生产化加分项（10.23–10.24）

- [ ] 混合检索（BM25 + 向量）与重排（Rerank）

## 长期（秋招后）

- 可观测性（trace / token 成本统计）
- 信创合规叙事完善
