# cs-agent · 企业知识库 + 智能客服 Agent

> 面向中国大陆企业落地场景的智能客服 Agent：**意图路由 / RAG 检索增强 / Function Calling 工具调用 / 多轮对话记忆 / 低置信度转人工**，支持国产大模型（GLM / Qwen / DeepSeek，OpenAI 兼容接口）与私有化部署。

## 一、项目背景

企业客服是大陆企业 AI 落地量最大的场景之一：客服人力成本高、响应慢、知识分散在产品文档 / 售后 FAQ / 规章制度中。cs-agent 的目标是做一个**稳定、可评测、可上线**的智能客服系统，而不是一个聊天机器人 Demo。

核心设计理念（区别于"套壳 Demo"）：

- **RAG 为地基**：企业知识库问答，检索不准一切归零；
- **工具调用为手脚**：查订单 / 查库存 / 建工单，Agent 要能干活；
- **人机协同为底线**：低置信度自动转人工，幻觉不上线；
- **量化评测为准绳**：每个版本都有指标，用数据说话。

## 二、核心能力（路线图）

| 能力 | 说明 | 版本目标 |
|------|------|----------|
| 意图识别与路由 | 咨询 / 查单 / 退款 / 投诉 分流 | v0.1 |
| RAG 知识库问答 | 文档解析 → 切片 → 向量化 → 混合检索 → 重排 → 生成 | v0.5 |
| Function Calling | 订单查询、库存查询、工单创建等工具 | v0.5 |
| 多轮对话记忆 | 短期滑窗 + 摘要压缩 + 长期记忆 | v1 |
| 低置信度转人工 | 置信度阈值 + 情绪识别，兜底人机协同 | v1 |
| 评测体系 | 意图准确率 / 检索命中率 / 首响延迟 / 转人工率 | v1.5 |
| 私有化部署 | 国产模型 + Docker 一键部署 | v2 |

## 三、技术架构（规划）

```
用户 → Web 前端 → API 网关
                    ├── 意图路由（意图分类 → 分流）
                    ├── RAG 链路（pgvector 混合检索 + 重排）
                    ├── 工具层（Function Calling：订单/库存/工单）
                    ├── 记忆层（短期上下文 + 长期向量记忆）
                    └── 兜底（低置信度 → 转人工 + 自动建工单）
模型层：国产大模型（GLM / Qwen / DeepSeek，OpenAI 兼容）
存储：PostgreSQL + pgvector / Redis
```

## 四、评测指标（v1.5 起）

- 意图识别准确率（目标 ≥ 90%）
- 知识库检索 Top-K 命中率（目标 ≥ 85%）
- 首响应延迟（目标 ≤ 3s）
- 转人工率与人工接管准确率
- 幻觉率（引用溯源校验）

## 五、设计原则

1. **Core First**：核心模块（Function Calling / ReAct / 检索）先手写实现，再对照框架，理解每一层在做什么；
2. **量化驱动**：没有指标的功能不算完成；
3. **生产可用**：错误重试、兜底降级、可观测性从 v0.1 就考虑。
